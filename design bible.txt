

# ChipKeep Design Bible v1.0

## Product Vision

ChipKeep is a **premium companion app for real-life Teen Patti games**.

It is **not** an online casino.

It is **not** a gambling app.

It is a **table management tool** that helps friends track chips, turns, pots, betting, and game history while playing together.

The app should feel closer to **Linear, Google Wallet, Revolut, and Notion** than to flashy casino games.

---

# Design Philosophy

Three principles guide every screen:

### 1. Fast

The host should complete almost every action within **two taps**.

Never bury frequently used actions.

---

### 2. Clear

Users should immediately know:

* whose turn it is
* current pot
* current stake
* active players
* available actions

No guessing.

---

### 3. Premium

Minimal.

Elegant.

High quality.

No unnecessary decoration.

No visual noise.

---

# Performance Goals

```

<SectionHeader />
```

Avoid duplicate UI code.

---

# AI Implementation Rules

Every coding model (Claude, DeepSeek, OpenCode, etc.) should follow these rules:

* Do **not** redesign approved screens.
* Recreate the approved mockups as accurately as possible.
* Reuse existing components instead of creating duplicates.
* Follow the spacing, typography, color, and animation rules in this Design Bible.
* Prefer composition over large monolithic components.
* Keep business logic separate from UI.
* Prioritize mobile-first layouts.
* Test UI changes before considering the task complete.

---

# Product Quality Checklist

Before any feature is considered complete:

* ✅ Matches the approved mockup.
* ✅ Follows the Design Bible.
* ✅ Responsive on common Android screen sizes.
* ✅ No layout overflow.
* ✅ Touch targets are comfortable.
* ✅ Typography is consistent.
* ✅ Animations are smooth and subtle.
* ✅ No browser-default dialogs.
* ✅ No TypeScript or runtime errors.
* ✅ Maintains a premium, modern feel.

---

## Future Design Principles

As ChipKeep grows (multiplayer, tournaments, statistics, Android app), every new screen should answer one question:

> **"Would this screen feel at home in a polished productivity app like Linear or Google Wallet?"**

If the answer is **yes**, it belongs in ChipKeep. If it feels like a flashy casino interface or a cluttered utility, it should be redesigned. This principle will help keep the app consistent even as it gains new features.
